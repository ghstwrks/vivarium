# Known gaps, deferred past v0.1

Everything below was found by the review pass over the v0.1 pivot and
deliberately left in place. None of it stops `viv run` from producing a
correct verdict, and each entry costs more to fix well than it costs to live
with for one release — either because the fix needs a design decision v0.1
should not be making in a hurry, or because the failure it guards against
requires a machine already misbehaving in a more interesting way.

The findings that were fixed are in the commit history; these are the ones
that were not.

1. **`viv gc` stops at the first failed deletion and says nothing about what
   it did.** `RunGC.execute` throws out of the loop, so a run whose bundle
   will not unlink strands every run after it in the plan, unmentioned. The
   sizes it prints are also measured *before* deletion and presented as
   fact, so a partial deletion reports the full figure as reclaimed.
   Deferred because doing it properly means gc reporting per-run outcomes
   rather than a plan and a total, which is a change to its output contract.
   `Sources/Vivarium/RunGC.swift`

2. **A test command abandoned at the grace-period timeout leaves its `ssh`
   process running.** `executeTest` gives up on the attempt but nothing
   kills the child, which holds a socket to a guest that is about to be
   force-stopped. Two lesser members of the same family: `GuestEcho` can
   print a late line after the run's summary, because the drain queues
   outlive the attempt; and `AskpassHelper`'s temporary directory survives a
   process that exits between creating it and its `defer`. Deferred because
   the fix wants a process handle that outlives the `withTimeout` boundary —
   an ownership change in `ProcessRunner`, not a patch.
   `Sources/Vivarium/Orchestrator.swift`, `Sources/Vivarium/ProcessRunner.swift`

3. **The `guest │ ` prefix goes into redirected output.** `viv run >
   out.txt` gets a file with the prefix on every line, which is the wrong
   thing to feed a log parser; it should be suppressed when the destination
   is not a terminal. Deferred as cosmetic, and because `results/
   test-stdout.txt` — the file anything mechanical should be reading — has
   never carried the prefix.
   `Sources/Vivarium/OutputStreaming.swift`

4. **gc decodes a whole `TestRunReport` to read two fields.** It needs
   `status` and `finishedAt`; a report written by a newer version, or
   half-written by a run that died mid-flush, fails to decode entirely and
   the run silently loses its date. A minimal projection would be both
   faster and more forgiving. Deferred because the existence check added in
   v0.1 already keeps such a run classifiable as finished — only its age is
   affected.
   `Sources/Vivarium/RunGC.swift`

5. **`--all` does not see dot-entries.** gc lists `runs/` with
   `.skipsHiddenFiles`, so a run directory whose name begins with a dot is
   invisible to a flag that promises to delete everything. Vivarium never
   creates such a name, which is why this is deferred rather than fixed, but
   `--all` should mean all.
   `Sources/Vivarium/RunGC.swift`

6. **`keptForInspection` conflates three different facts.** It is true for
   `--keep-vm` on a passing run, for a failing run that kept everything on
   purpose, and for a run whose cleanup simply failed. A consumer cannot
   tell "kept because you asked" from "kept because deletion broke".
   Deferred because splitting it is a `report.json` schema change.
   `Sources/Vivarium/Orchestrator.swift`, `Sources/Vivarium/TestRunReport.swift`

7. **The artifact inventory stats through symlinks.** A harvested symlink
   pointing at a host file contributes that file's size to
   `artifactByteCount`, which leaks a fact about the host into a report
   about the guest. Small, and bounded by what the harvest copies, but the
   inventory should `lstat`.
   `Sources/Vivarium/Orchestrator.swift`

8. **`viv gc --all` asks for no confirmation.** It deletes every run
   directory, `results/` included, on one line with no prompt and no
   `--yes`. `--dry-run` exists and is cheap, which is the current answer;
   a destructive default deserves better than a convention.
   `Sources/Vivarium/CLI.swift`

9. **`RunGC.plan`'s `runsRoot` parameter is validated against the global
   home.** The containment check compares whatever root it is passed against
   `VivariumHome.root` rather than against that root's own home, so the
   parameter is only safe for the one value the CLI passes. Deferred: no
   caller passes anything else, and the parameter exists for tests.
   `Sources/Vivarium/RunGC.swift`

10. **`report.md`'s table breaks on a `|` in the test command.** A command
    containing a pipe splits the cell it is in. Only the human-readable
    half is affected — `report.json` is unambiguous — so this is a rendering
    bug, not a data one.
    `Sources/Vivarium/TestRunReport.swift`

11. **A test that finishes in the last instant of its budget can be reported
    as timed out.** `waitForExit` races the killer task against the
    termination latch; a process that exits while the timeout is firing can
    have `didTimeOut` set anyway, turning a pass into a timeout verdict. The
    window is milliseconds wide at the end of a budget the test had already
    almost exhausted, which is why it waits — but a verdict decided by a
    race is the wrong kind of flake to keep.
    `Sources/Vivarium/ProcessRunner.swift`

12. **A NUL byte in a manifest string reaches the guest's shell.**
    `VivManifest` validates identifiers and rejects a pattern equal to the
    here-document delimiter, but nothing rejects a NUL, which truncates the
    string somewhere inside `zsh` rather than being rejected on the host.
    Deferred as theoretical — the manifest author already controls `test` —
    but a parser that claims strictness should reject it.
    `Sources/Vivarium/VivManifest.swift`

13. **`CodeStager.checkSpace` fails open, and its documentation does not
    say so.** If the volume's free space cannot be read, staging proceeds
    with no headroom check at all; the docstring reads as an absolute
    refusal. Deferred because failing closed on an unreadable resource value
    would refuse runs on filesystems that simply do not report capacity.
    `Sources/Vivarium/CodeStager.swift`
